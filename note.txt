================================================================================
1. PROJECT INTRODUCTION
================================================================================
THAMILI (தமிழி) is a modern, bilingual (Tamil and English) Artificial Intelligence 
Admin Dashboard and unified AI Hub platform. The website is engineered to empower 
administrators and Tamil-speaking users with direct access to next-generation AI 
tools entirely localized in the Tamil language, while providing a powerful, 
responsive administrative control panel to monitor usage, manage users, configure 
tools, and track system analytics.


================================================================================
2. PROJECT OBJECTIVE
================================================================================
The core objectives of the THAMILI project are:
1. Bridging the Digital Divide: Making advanced generative AI technologies 
   (Chatbots, Video Generation, Image Synthesis, Code Generation, Text-to-Speech 
   Audio, and Content Writing) accessible to Tamil-speaking individuals in their 
   native script and Tanglish.
2. Centralized Platform Administration: Providing a secure, intuitive dashboard 
   for platform administrators to monitor key metrics (active users, query counts, 
   token usage, server health), review recent activity logs, manage subscriptions, 
   and moderate generated content.
3. High Performance & Dual Architecture: Delivering lightning-fast user 
   interactions through a modern React Single Page Application (SPA) with smooth 
   client-side routing, paired with a lightweight Node.js/Python backend API server.

3. FRONTEND
================================================================================
The frontend is the visual and interactive user interface of the THAMILI platform.

A. Frontend Technologies Used:
   - React 18 (v18.3.1): Core UI library for building modular, reusable component 
     hierarchies.
   - React DOM (v18.3.1): Renders React components efficiently into the browser DOM.
   - React Router DOM (v6.26.2): Manages client-side routing, navigation between 
     pages without full page reloads, dynamic URL parameters, and fallback routes.
   - Vanilla CSS3 Design System: Custom-crafted responsive design system with 
     modern dark-mode glassmorphism, glowing gradient accents, CSS Grid, and 
     Flexbox layouts.
   - Google Fonts Typography: Mukta Malar (for authentic Tamil script rendering), 
     Outfit, and Inter (for clean, modern UI numerals and English headings).
   - Vite 5 (v5.4.6): Next-generation frontend build tool and development server 
     providing Instant Hot Module Replacement (HMR).

B. Key Frontend Source Files:
   - index.html: Entry HTML document with Google Fonts, favicon, and root mount point.
   - src/main.jsx: Application bootstrap file that injects stylesheets and renders 
     the root React tree.
   - src/App.jsx: Central routing engine registering all 16 page routes and global 
     providers.
   - src/components/layout/:
     * Layout.jsx: Common layout wrapper containing Sidebar, Header, and content area.
     * Header.jsx: Top bar with global search, language switcher (தமிழ் / EN), 
       notifications, theme toggle, and Admin profile quick access.
     * Sidebar.jsx: Left navigation menu with active route highlighting, badge counts, 
       and links to all 16 sections.
   - src/components/common/:
     * UsageChart.jsx: Interactive visual analytics chart for weekly AI platform usage.
     * ToastContainer.jsx: Floating alert notification system for user action feedback.
   - src/components/modals/:
     * AdminProfileModal.jsx: Full-featured popup modal allowing administrators to 
       view and edit profile details (Name, Username, Email, Phone, DOB, Gender, Bio).
   - src/context/:
     * AdminProfileContext.jsx: Global state manager for administrator identity.
     * I18nContext.jsx: Bilingual localization provider for seamless Tamil/English toggling.
     * ToastContext.jsx: Global notification dispatcher.
   - src/data/translations.js: Complete bilingual key-value dictionary containing 
     over 400+ translation phrases across all dashboard pages.

C. How the Frontend Displays and Operates:
   - When the user opens the website, React mounts the Layout component into #root.
   - The user interface dynamically updates based on state changes without reloading 
     the web browser.
   - The Admin Page is structured with a multi-column responsive dashboard grid: 
     a main column containing a Hero Welcome Banner, 6 Quick Access AI Tool Cards, 
     Platform Usage Analytics Chart, and Security/Speed Badges; and a right side column 
     displaying Live Key Statistics (Registered Users, Site Visitors, Active Users), 
     Recent Activity Logs, and a Promotional Banner.
   - Interactive events (button clicks, form inputs, language changes, profile edits) 
     update React state and trigger real-time UI re-renders and REST API network requests.

4. BACKEND
================================================================================
A functional backend server is implemented in the THAMILI project to handle API 
routing, AI processing, file serving, and external LLM communication.

A. Backend Technologies Used:
   - Node.js Runtime (Primary Backend - server.js): Built using native Node.js 
     standard libraries (http, https, fs, path, crypto, url) without heavy third-party 
     framework bloat, listening on port 8080 (or process.env.PORT).
   - Python 3 Server (Alternative Backend - server.py): Python standard library 
     HTTP server (http.server, urllib.request, socketserver) providing AI chat routing 
     and UTF-8 console output.

B. What the Backend Does:
   1. Serves the static production frontend build files (HTML, CSS, JS, Images).
   2. Acts as a secure API Gateway connecting frontend client requests to external 
      AI LLM engines (Google Gemini API, OpenAI / Groq API, Pollinations AI, Google TTS).
   3. Houses Built-in Native Offline Intelligence Engines: If external API keys are 
      not provided or internet connectivity is limited, the backend executes built-in 
      rule-based Tamil/English intelligence logic to return instant, accurate answers, 
      code templates, content articles, and image links.
   4. Manages In-Memory State: Tracks asynchronous video generation job queues and 
      processing states.

C. Frontend → Backend Communication:
   - The React frontend communicates with the Node.js backend using standard 
     asynchronous HTTP requests via the browser's built-in `fetch()` API.
   - Payloads and responses are structured as standardized JSON (application/json) 
     with CORS headers enabled.

5. API (APPLICATION PROGRAMMING INTERFACE)
================================================================================
APIs are implemented and actively utilized throughout the THAMILI project.

A. Internal Custom REST API Endpoints (server.js):
   1. POST /api/chat
      - Purpose: Multi-turn conversational AI chatbot.
      - Data Handled: User query, conversation history array, selected language (ta/en).
      - Response: AI-generated response text formatted in clean Markdown.
   2. POST /api/code/generate
      - Purpose: Full-Stack software generator and multi-file code architect.
      - Data Handled: Prompt, architecture mode (fullstack/frontend/backend), language.
      - Response: Multi-file project structure (package.json, server.js, index.html, 
        style.css, app.js) with runnable code.
   3. POST /api/content/generate
      - Purpose: Multi-format copywriting and content transformation studio.
      - Data Handled: Topic prompt, category (blog/social/article), tone, action, language.
      - Response: Structured article title, formatted body text, word count, character count.
   4. POST /api/image/generate
      - Purpose: Text-to-Image synthesis studio.
      - Data Handled: Description prompt, visual style (Photorealistic/Anime/3D/Art), aspect ratio.
      - Response: High-resolution image URL, metadata, and generation parameters.
   5. POST /api/image/edit
      - Purpose: Natural language image editing and transformation.
      - Data Handled: Source image URL / data, transformation instruction.
      - Response: Transformed image URL and comparison data.
   6. POST /api/video/generate
      - Purpose: Text-to-Video and Image-to-Video generation engine.
      - Data Handled: Motion prompt, source image, style, duration, aspect ratio.
      - Response: Unique video job ID, rendering status, and video asset URL.
   7. GET /api/video/status
      - Purpose: Video generation job status polling.
      - Data Handled: Job ID query parameter.
      - Response: Job progress percentage, completion status, and downloadable MP4 URL.
   8. POST /api/audio/tts
      - Purpose: Real Text-to-Speech (TTS) audio synthesizer.
      - Data Handled: Input text, language code (ta/en), voice profile.
      - Response: Streamable audio URL (audio/mp3) and speech parameters.
   9. POST /api/upload
      - Purpose: Secure media data receiver.
      - Data Handled: Base64 data URL, file name, MIME type.
      - Response: Server confirmation, file URL, and metadata.
   10. GET /api/status
       - Purpose: System health check and active AI provider detector.
       - Response: Online status, active provider name, and enabled tool list.

B. External Third-Party APIs Integrated:
   - Google Gemini API: For advanced conversational intelligence (gemini-1.5-flash).
   - OpenAI / Groq API: For high-speed LLM text and code completions.
   - Pollinations AI Neural Engine: For real-time text-to-image synthesis.
   - Google Translate TTS API: For natural Tamil and English voice synthesis.
   - Google Fonts API: For web font stylesheets.

12. FRONTEND → BACKEND → API → DATABASE CONNECTION FLOW
================================================================================

1. Frontend Layer (React + CSS):
   - Captures user input (e.g., text prompt in AI Chat or Image generator).
   - Performs client-side form validation and shows loading spinners.
   - Dispatches an asynchronous `fetch('/api/...')` call with JSON body.

2. Backend Gateway Layer (Node.js server.js):
   - Listens on port 8080, parses incoming JSON request bodies, and verifies routes.
   - Determines whether external LLM API keys exist (e.g., GEMINI_API_KEY).

3. API Integration Layer:
   - External APIs: If API keys are active, backend forwards requests to Google Gemini, 
     OpenAI, Groq, Pollinations AI, or Google TTS.
   - Native Fallback APIs: If offline or keys absent, backend executes native Tamil/English 
     logic engines to generate intelligent responses.

4. Database / Storage Layer:
   - No external SQL/NoSQL database server is used.
   - Client persistence is executed directly by the Frontend using Browser LocalStorage 
     (`thamili_admin_profile`, `thamili_lang`, `thamili_ai_chat_history`).
   - Server-side transient state is stored in Node.js In-Memory Maps (`videoJobs`).

5. Response & Presentation Layer:
   - Backend sends HTTP 200 OK with formatted JSON.
   - Frontend updates React component state, renders result cards/previews, and displays 
     success toast notifications.

16. OVERALL WORKING PROCESS
================================================================================
The THAMILI project operates as a unified, full-stack bilingual web platform. 
When the project starts, the Vite development server compiles the React frontend, 
while the Node.js backend server (`server.js`) starts listening on port 8080. 
When the administrator opens the website in a web browser, React mounts the core 
Layout containing the Sidebar, Header, and the Dashboard Page. 

The dashboard immediately presents key platform metrics, daily usage graphs, recent 
activity logs, and 6 quick-access cards for the THAMILI AI Hub tools. When the admin 
or user interacts with any AI tool—such as chatting in Tamil, generating images, 
creating full-stack code, synthesizing speech, or generating videos—the React frontend 
sends an asynchronous HTTP request to the backend REST API endpoints (`/api/chat`, 
`/api/code/generate`, `/api/image/generate`, etc.). The backend processes the request 
using either connected AI APIs (Google Gemini, Pollinations AI, Google TTS) or its 
built-in native intelligence engines, returning structured JSON responses. The frontend 
instantly updates the view, renders formatted outputs or media players, and saves user 
preferences in Browser LocalStorage without requiring full page reloads.
